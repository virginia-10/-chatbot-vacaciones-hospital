
# Chatbot Vacaciones Hospital

Este proyecto simula un chatbot para gestionar solicitudes de vacaciones del personal hospitalario.

## Funcionalidades

- Solicitud de días de vacaciones
- Validación de datos ingresados
- Aprobación o rechazo automático
- Manejo de errores (camino infeliz)

## Tecnologías utilizadas

- Python (simulado)
- WhatsApp Business (propuesto)
- Base de datos en Excel

## Descripción

El sistema permite que un usuario solicite días de vacaciones mediante una conversación automatizada. El chatbot verifica la información ingresada y responde según la disponibilidad de días.
